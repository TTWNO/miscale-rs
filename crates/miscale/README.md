# miscale

Sans-io, `no_std`, allocation-free weigh session for the Xiaomi Smart Scale
S200 (MJTZC02YM): log in with the device token, open the encrypted spec
channel, send the hello and user profile, and turn what the scale streams
into live readings and one final weight.

Part of [miscale-rs](../../README.md). Licensed under MIT OR Apache-2.0.
