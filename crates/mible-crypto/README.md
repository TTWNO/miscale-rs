# mible-crypto

`no_std`, allocation-free cryptography for the Xiaomi Mi BLE login: the
redacted, zeroising login `Token`, the HKDF-SHA256 login key schedule, the
HMAC-SHA256 proofs, and the AES-128-CCM session cipher.

Built on the RustCrypto crates. Part of [miscale-rs](../../README.md).
